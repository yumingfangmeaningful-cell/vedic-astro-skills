# 断卦理法(核心)

## 一、定位论(第一要素)

定位就是给三宫"安角色"——决定每宫在这一问里代表谁、代表什么。**卦的走向皆围绕定位, 定位是断卦第一要素。**

- 三宫不是定死的"天=对方、人=自己/结果": 天可为人或事, 地也可为人或事, 有时时辰也有妙用。通常以天宫为对方, 但要活看。
- 找类神即定位: 问电子产品注意速喜, 书本注意大安, 房子注意空亡留连, 发烧炎症注意速喜, 呼吸系统注意赤口。卦中没有这些宫, 就一切按照卦及问题走。
- 例1(面试): 空亡赤口大安酉。空亡定为公司, 大安定为我/简历。大安克空亡=去公司入职; 空亡生赤口=拒绝, 赤口克大安=排斥卦主 → 不要卦主。
- 例2(矿难): 小吉大安留连未。以大安定位(被困者), 大安入墓(未)=被压被困; 留连=困顿缠绕、搜救进度缓慢; 应期为丑日(冲开墓库之意可参)。
- 例3(钓鱼): 大安留连赤口未。同一卦可多重定位反复换象: 大安=天气好/主静/坐着钓; 赤口克大安=钓鱼这个动作; 大安入墓=很难钓到; 留连=湖水杂乱脏/慢久等; 赤口=鱼/工具/自己, 赤口主缺=鱼少/没经验; 大安是鱼竿、留连是线、赤口是钩=取象"钓鱼", 只有工具鱼却寥寥。反馈: 四小时钓到一条小鱼。
- 多重定位可叠加合观(如科三考试例: 赤口分别定位为"错误/人/路"三次, 合起来完整解读)。

## 二、生克流向论

- 生: 给予、保护、关爱、泄耗, 是五行力量的传递转化, 围绕象论。
- 克: 克制、制约、打架、批评、看不起——**不是克死**, 主象义。
- 注意方向: 是我生克他宫, 还是他宫生克我。生克大多指意向, 不是"生他我就弱了""被克就死了"。
- 点与点互相转换: 空亡克小吉, 以小吉为定位点则论小吉被克之象(肾不好/行动不利/断水); 以空亡为自己为定位点, 小吉是钱, 被克主自己拿钱了。
- 速喜生空亡: 可论感情生空、心血虚; 但若以空亡为我, 速喜生我反而可能是对方喜欢我、喜事向我走来 → 又回到定位。
- 流向串联断事(卖车例): 大安赤口空亡申。大安=车, 空亡=店=自己, 赤口=交易转手。空亡生赤口=我去交易, 赤口克大安=车被克出去=卖掉了。
- 三宫内千变万化, 终归回到定位问题; 举一反三, 勿按部就班。
- 通关顺生: 如水生木、木生火, 则水克不到火, 火的能量反增(但象上未必"动", 如大安速喜为想法增强)。
- 道传补充: 三宫生克是三才之应, 谓助谓制, **不改落宫之果**——生克助制不推翻落宫定下的基调。

## 三、空亡论

见 gongwei.md 空亡宫断语要点。核心: 空亡到底空不空, 一看三宫气势流向与象, 二看卦主心态及问题; 问场所时空亡常常就是场所本身; 象已出现处勿再套"心态"解。
例: 空亡留连空亡戌(校长被双规, 问平安否)——空亡空亡不是"无事", 而直接表示牢狱, 开始就在牢狱中, 最后出不来。
例: 大安赤口空亡酉(能否找到充电桩)——大安赤口=车子充电, 空亡=场所, 大安克空亡=找到了。

## 四、墓库论

五行墓库: 木墓在未, 火墓在戌, 金墓在丑, 水土墓在辰。(宫五行对时辰地支论入墓)

墓库之象: 包容, 顿藏, 收藏, 死亡, 停止, 闭塞, 困顿。一般论卦不按旺衰分墓库。
- 人宫为我为事体而入墓: 问学业=昏昏沉沉发挥不出水平; 问财运=财运不济。总之困顿之象, 但**须先定位成卦主或事情**才能这么论。
- 例(科三): 小吉速喜赤口丑。赤口(金)入丑墓。三重定位: 赤口=错误(单宫论断过不去); 赤口=人(入墓=东西忘光、没状态); 赤口=路(赤口生小吉=路上考试)。合断: 错误被速喜(电子监控)克=被发现, 又入墓状态不好 → 没过。
- 辰戌丑未为四库, 凡可藏人存物之地皆是墓库象: 医院、牢房、书房、厨房、衣柜、冰箱、地窖、水库、车库、银行、影院、家宅、公司、学校、庙宇等。辰=水库湖泊土堆; 戌=庙宇弹药库电厂电脑房油库; 丑=银行交易所; 未=森林木材市场。

## 五、地支运用(重要告诫)

三宫地支择法(君谦, 脚本已自动给出): 各宫阴阳支为 大安卯/寅、留连未/戌、速喜巳/午、赤口酉/申、小吉子/亥、空亡丑/辰; 位置定阴阳(天阳、地阴、人阳), 宫吉为阳、凶为阴; **宫与位阴阳相同取阴支, 不同取阳支**。例: 大安小吉空亡 → 卯、子、辰。

用法边界(君谦强调):
- 这套地支**主要用于应期**, 或某些卦中的取象/路线, 只是多出一个参考点; 细论应期还要明理及象。
- **三宫内基本不论地支的刑冲破害合**(象上万万不可), 也不要分燥土湿土——每宫本已包含各地支, 三宫信息已足, 何须地支"捣乱"。小吉克速喜就是水克火, 无需再论巳亥冲。
- 时辰在极大程度上不参与三宫的刑冲破害合, 除非应期或时辰在卦中有明确"角色"。
- 勿把八字论身强身弱那套搬来。

地支合冲刑害(供应期与特定场合参考):
- 六合: 子丑逆合凑合(先好后坏/婚姻凑合过); 寅亥破合(好中有坏); 卯戌淫合自焚(未婚同居); 辰酉暗合(私下定不公开); 巳申刑合(在一起就吵分开又想); 午未明合(公开实心)。合主和好羁绊、能量聚集; 时间上表缓慢, 空间上表长久; 生合愈合愈好, 克合捆住往死里克; 合绊为能量受阻、吉祥成事迟, 待冲开时。子丑午未内合近合主至亲, 寅亥巳申远合短合主朋友, 卯戌辰酉中合主知己。
- 三合局: 寅午戌合火局主财婚吉庆(怕亥子水破); 亥卯未合木局主纠缠交易; 巳酉丑合金局多阴私暗昧; 申子辰合水局主争战打斗搬迁。三合能量最大, 多有团队/拉帮结派性质。
- 六冲: 子午冲水火灾疾; 丑未冲冤仇诅咒; 寅申冲更改计划; 卯酉冲车惊车祸; 辰戌冲争讼斗打; 巳亥冲生气索要。冲主矛盾变动离散, 时间上表快速; 凶事喜冲吉事不宜; 子午卯酉正冲凶大, 丑未巳亥斜冲凶轻, 寅申辰戌角冲凶一般; 吉神遇散未能喜, 凶神遇散而无灾。
- 三刑: 寅巳申恃势之刑(知恩不报官司牵连); 丑未戌无恩之刑(仗势欺人勾心斗角); 子卯无礼之刑(母子反目三角恋爱门户不正); 辰午酉亥自刑(不择手段身心不健)。
- 六害: 子未、丑午、寅巳、酉戌、卯辰、申亥——小人加害、背后捅刀。

## 六、体用关系

落宫为体, 时辰为用(**在"发生的卦"才看体用**; 卦成若需乃参体用, 不需则不观)。
- 体生用: 小凶, 泄耗付出投资, 未来要付出很多(不全以凶论, 有时是投资)。
- 用生体: 大吉, 外力相助, 发展趋势好。
- 用克体: 大凶, 受阻, 付出多也未必成; 但克亦有占有/克制/改造/考察义(问工作可解为压力, 问上级看法可解为考察期)。
- 体克用: 小吉, 主动努力挖掘可得(测失物=主动去找很可能找到)。
- 体用比: 阴阳相异为比助(吉, 两相互助); 阴阴或阳阳为比劫(凶, 竞争互损)。宫阴阳: 大安速喜赤口空亡为阳, 小吉留连为阴。例: 赤口阳金遇酉时阴金为比助, 遇申时阳金为比劫。

## 七、旺相休囚死

以时辰为令: 同令为旺, 令生我为相, 我生令为休, 我克令为囚, 令克我为死。
例(速喜速喜速喜 X时, 问感情): 火时=旺, 四火无根灭得更快, 很快分手; 木时=相, 有根能量足, 热恋很长; 土时=休, 火入土, 冷淡分手异地; 金时=囚, 争吵、金钱问题; 水时=死, 直接灭了, 比火令更快分手。
注意(道传): 落宫的宫象吉凶本身**不因休囚死而否定**——夏天落赤口不能以"夏金死"否其凶性; 旺衰只调强弱, 宫有宫象、事应已定。三个宫能量小于时辰。

## 八、十二长生像意

(宫五行对时辰地支; 木生亥、火生寅、金生巳、水土生申, 脚本已自动标注)
- 长生: 开始、新的开始、起点来源靠山获救
- 沐浴: 桃花、未定漂浮、裸露享受破财
- 冠带: 生发、发展阶段欣欣向荣、穿衣包装升级
- 临官: 成熟、周到缜密、公家官府出仕、快要成功、亦有危险巴结之意
- 帝旺: 鼎盛、到顶注意改革
- 衰: 退落下滑、无力软弱不景气、婚姻感情转平淡
- 病: 问题错误、疾病缺点毛病把柄
- 死: 低沉、死气沉沉钻牛角尖不变通、寂寞安静
- 墓: 禁锢、被困、收藏关闭管制陷阱昏沉堵塞(参墓库论)
- 绝: 情绝、不留余地、绝境分手死心冷酷停止消失
- 胎: 想法、内心酝酿未说出、怀孕、初步计划幼稚起步
- 养: 懒惰、行动迟缓休养、有靠山不愿动、贪婪、扶持教育

## 九、应期断法

应期入手(综合运用, 不必全上):
1. 落宫季节归属: 大安春(寅卯辰月), 留连春夏(辰巳月)或四季土月(辰戌丑未), 速喜夏(巳午未月), 赤口秋(申酉戌月), 小吉冬(亥子丑月), 空亡冬春(丑寅月)或论阴阳取辰戌月。
2. 六神地支(择法所得支)排应期。
3. 六神数应(含隐数)。
4. 体用与三宫生克远近: 泄对方力量又生自己的月份为佳(讨债例: 速喜赤口赤口午, 对方速喜得令克自己赤口, 打不过 → 等生金或克火的月份, 建议土月[泄火生金], 赤口取1, 下月即未月 → 下月去要)。
5. 墓库应期: 入墓者常应冲开墓库之日(矿难例大安木入未墓, 应期丑日)。
6. 卦气外应细观。取年取季取月取日取时, 落宫自有其义, 据问而断, 附上下浮动、择阴阳奇偶。
7. 婚期: 明卦主生肖, 依六亲内外生克(男者克出、女者克内)寻缘之六神何属, 复据体用生克、落宫数应、取年时干支五行定何年何期。

## 十、转太极

卦有太极点(问题核心)。转太极=转核心/转问题, 新问题须与原问题有关。
1. 六亲转太极: 以落宫(我)论——生我者父母, 我生者子孙, 我克者妻财, 克我者官鬼, 同我者兄弟, 同异者小人(同五行异宫, 如落空亡时留连不作兄弟作小人)。逐宫按所需六亲变换得新卦(脚本可自动输出)。土宫取舍: **阳时男测、阴时女测取留连; 阳时女测、阴时男测取空亡**。例: 速喜大安赤口 → 父母卦=大安小吉留连, 妻财卦=赤口留连大安。据需而转, 无需者勿转。
2. 事件关系转太极: 循事件前后左右之理转。如问项目赚钱几许: 落宫为项目, 项目所生者为获益, 项目所克者为损耗, 生项目者为投资, 克项目者为花销。又如问男女朋友: 落宫为女, 天宫(缘分天时)为男。
3. 神煞转太极: 事急变且不在六亲事件之列时, 按神煞类象转落宫(青龙=事业学业孕喜赌; 腾蛇=田宅阴私匪盗; 朱雀=文书婚喜电火飞行; 白虎=官非伤险口舌警司; 六合/玄武=酒食合作预定出行; 勾陈=牢狱果报福贵宅地)。落宫转毕, 天地二宫可不随转(天地为起因经过, 卦成即定)。

## 十一、三宫具象法(进阶)

按三宫阴阳成八卦以佐断: 大安速喜小吉为阳爻, 留连赤口空亡为阴爻。具象天盘取"人天地"序成卦, 具象地盘取"天地人"序, 具象人盘取"天人地"序; 得卦后观该盘与八卦之五行生克(克出/生出/克内/生内/同), 依生克复转三宫得具象。具象基于本卦吉凶之上, 助深透前因后果, 不可另出结论。(八卦类象见 bagua.md)

## 十二、断卦总则提醒

- 卦问为基: 无事不占, 起而无事则卦理匮明。
- 宫有宫象, 事应已定; 生克为助制, 不改其果; 旺衰调强弱, 不翻吉凶。
- 象要活断, 举一反三, 忌按部就班; 灵机与外应可参。

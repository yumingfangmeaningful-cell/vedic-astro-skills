# 六神(六兽)详解

六神是辅助断卦的取象工具，临不同六亲组合出不同信息之象。六神不决定吉凶(吉凶看用神旺衰)，但能丰富断卦的细节和画面感。

## 六神排法

按占卦当日天干，从初爻起排:
- 甲乙日: 初爻起青龙
- 丙丁日: 初爻起朱雀
- 戊日: 初爻起勾陈
- 己日: 初爻起腾蛇
- 庚辛日: 初爻起白虎
- 壬癸日: 初爻起玄武

顺序: 青龙→朱雀→勾陈→腾蛇→白虎→玄武，从初爻排到上爻。

## 各神详解

### 青龙 (五行属木，方位东)
**吉神。** 主喜庆、吉祥、婚姻、孕育、财喜、贵人。
- 临官鬼: 有官位荣升之喜，女测为佳夫
- 临妻财: 正道之财，男测为贤妻美妇
- 临父母: 吉利文书、房产之喜
- 临子孙: 子女聪慧，财源持续
- 临兄弟: 兄弟和睦，朋友得力
- **衰弱时:** 酒色之患、虚荣、表面风光

### 朱雀 (五行属火，方位南)
**主口舌是非。** 主文书、信息、言语、通讯、诉讼。
- 临官鬼: 口舌官非、诉讼、火灾
- 临妻财: 快捷之财、信息带来的财
- 临父母: 文书顺利、消息到来
- 临子孙: 能歌善舞、演讲才华
- 临兄弟: 因口舌破财、争吵
- **职业取象:** 教师、律师、记者、广播、翻译

### 勾陈 (五行属土，方位中)
**主迟滞牵连。** 主田土、房产、慢、旧事、纠缠。
- 临官鬼: 陈年旧案、纠葛不清
- 临妻财: 久远之财、房产之利
- 临父母: 老房子、旧文书、合同
- 临子孙: 诚实后代、运势缓慢
- 临兄弟: 合伙纠缠、旧友
- **性格取象:** 诚实老练、行动迟缓、固执

### 腾蛇 (五行属土，附阴)
**主惊怪虚惊。** 主梦寐、恐惧、怪异、犹疑不决、虚假。
- 临官鬼: 怪病、惊吓、恐惧之灾
- 临妻财: 不义之财、来路不明之财
- 临父母: 虚假文书、不实消息
- 临子孙: 虚惊一场、惊梦
- 临兄弟: 不可靠之人、口是心非
- **特征:** 曲折、缠绕、蛇行之象

### 白虎 (五行属金，方位西)
**凶神。** 主病患、死丧、血光、破财、凶险。
- 临官鬼: 重病凶灾、血光之灾、急病
- 临妻财: 因财致祸、突发破财
- 临父母: 长辈病灾、房屋损坏
- 临子孙: 子女病灾、幼儿不安
- 临兄弟: 朋友灾祸、竞争凶险
- **特征:** 急速、凶猛、刚烈

### 玄武 (五行属水，方位北)
**主暗昧盗窃。** 主偷盗、欺骗、暧昧、私情、阴谋。
- 临官鬼: 盗贼、小人暗害、暗病
- 临妻财: 暗财、偏财、赌博、暧昧之财
- 临父母: 伪造文书、虚假信息
- 临子孙: 私生子、不正当娱乐
- 临兄弟: 酒肉朋友、骗子、赌友
- **特征:** 隐秘、暧昧、不光明

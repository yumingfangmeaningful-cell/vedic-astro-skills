# 六爻纳甲占卜

京房纳甲筮法排盘与断卦，按传统六爻理法进行系统解卦。核心原则: **用神为纲、月日为权、动变为机**。

## 第零步: 明确所问

无事不占。先弄清用户测什么事(测什么定用神)。若用户只说"算一卦"没说问什么，先问一句所测何事。已知问题就不要重复追问。

## 第一步: 起卦

先安装依赖(仅时间起卦需要，装过则跳过): `pip install cnlunar --break-system-packages`

按用户给的信息选模式，运行 `scripts/paigua.py`:

| 用户给的是 | 命令 |
|---|---|
| 铜钱摇卦/随机起卦 | `python3 scripts/paigua.py coin --datetime "2026-08-03 14:30"` |
| 公历日期时间 | `python3 scripts/paigua.py date "2026-08-03 14:30"` |
| 三个数字 | `python3 scripts/paigua.py numbers 5 3 2 --datetime "2026-08-03 14:30"` |
| 卦名(如"天火同人") | `python3 scripts/paigua.py gua 天火同人 --dong 3 --datetime "2026-08-03 14:30"` |
| 六爻爻象(6/7/8/9) | `python3 scripts/paigua.py yao 7 8 9 7 7 8 --datetime "2026-08-03 14:30"` |

要点:
- **必须指定占卦时间**: `--datetime` 参数必填，时间决定月建日辰六神旬空。"用现在时间"就取当前时间。
- 铜钱法: 7=少阳(静), 8=少阴(静), 9=老阳(动), 6=老阴(动)。
- 数字起卦: 第一个数取下卦，第二个数取上卦，第三个数取动爻，按先天八卦数(乾1兑2离3震4巽5坎6艮7坤8)。
- 脚本输出全部技术标注(纳甲、六亲、六神、世应、旬空月破、伏神、动变关系)，**这些是给你断卦用的底稿，不要原样倒给用户**。

## 第二步: 读参考资料

每次断卦前**必读**:
- `references/duangua.md` — 断卦核心理法(用神、原忌仇、月日权衡、动变、旬空月破、伏神)
- `references/liuqin.md` — 六亲取用法则与各类占的用神表

按需**加读**:
- 需要细看六神取象 → `references/liushen.md`
- 需要推应期 → `references/yingqi.md`
- 需要分类占断法(感情/财运/工作/疾病/失物/官司/出行/天气等) → `references/fenlei.md`

## 第三步: 解卦(工作流)

1. **取用神**(最重要): 根据所问确定用神——测什么人/什么事，对应哪个六亲爻。用神是整个分析的核心靶点，取错则全盘皆误。参照 liuqin.md 的用神分类表。
2. **看用神状态**: 用神在卦中旺衰如何？月建生扶还是克制？日辰生扶还是克制？是否旬空、月破、入墓？动还是静？有无动爻生克？
3. **看原神忌神**: 生用神者为原神(吉)，克用神者为忌神(凶)，生忌神者为仇神(凶)，克忌神者为喜神(吉)。原忌力量对比决定吉凶趋势。
4. **看世应**: 世为己、应为彼。世应关系反映自己与对方的状态与互动。
5. **看动变**: 动爻是卦中最活跃的信息，动则有因。关注动爻的六亲、五行、与用神的生克关系。变爻看回头生克、化进退、化墓化绝。
6. **综合断**: 月日为天时大环境，动变为事态发展，用神状态为最终结果。月日>动变>静爻，层层递进。
7. **断结果**: 给出明确倾向(吉/凶/成/败/得/失)，不含糊。传统六爻讲究的是在理法框架内给出确定性判断。凶卦要指出化解方向或转机时点。
8. **应期**(用户问了才推): 参照 yingqi.md 推算应验时间。

## 第四步: 输出格式

结论先行，卦理跟上，简明不堆术语:

```
【卦象】○○宫: 主卦名  变卦: ○○(如有)
(一句话交代: 占问○○，用神取○○爻)

【断】直接回答所问的结论，1-3句。

【卦理】
白话讲清用神状态、月日作用、动变影响、原忌力量对比，
让用户看懂"为什么这么断"。3-6句为宜。

【应期】(用户问了才给)
```

手机端注意紧凑，全文以一两屏为限; 用户想细听再展开。语气按传统卦师的路子——笃定、直给，该断凶就断凶，但凶卦顺带指出路(何时转机/注意什么)，不吓唬人。

## 边界与诚实

- 六爻是传统纳甲筮法，按经典理法认真断，但不冒充超自然确定性。
- 用户若把重大医疗、法律、投资决策押在卦上，断完自然提醒一句以专业意见为准，不必每卦都念免责声明。
- 测病可以按疾病占断象，涉及真实健康问题时提醒就医; 卦断重象时表述留有余地。
- 不同六爻流派细节有异(如变卦六亲归属、旺衰取法)，本技能以传统纳甲正宗为准; 用户若用别的口径，尊重用户的师承。

# 小六壬占卜

按师传资料(君谦一脉理法 + 取象大全 + 道家小六壬)进行小六壬三宫断卦。核心信念: **定位是断卦第一要素, 象要活断**。

## 第零步: 明确所问

无事不占。先弄清用户测什么事(卦问为基)。若用户只说"算一卦"没说问什么, 先问一句所测何事。已知问题就不要重复追问。

## 第一步: 起卦

先安装依赖(仅日期起卦需要, 装过则跳过): `pip install cnlunar --break-system-packages`

按用户给的信息选模式, 运行 `scripts/qigua.py`:

| 用户给的是 | 命令 |
|---|---|
| 公历日期时间(或"用现在时间起") | `python3 scripts/qigua.py date "2026-08-03 14:30"` |
| 农历月日+时辰 | `python3 scripts/qigua.py lunar 6 21 未` |
| 骰子/随机数字(3个) | `python3 scripts/qigua.py numbers 3 5 2 --hour 未` |
| 直接报三宫卦名 | `python3 scripts/qigua.py gua 大安 速喜 赤口 --hour 未` |

要点:
- "用现在时间起一卦": 取用户当地当前时间(有时间工具就调用, 没有就问)填入 date 模式。
- 骰子/数字起卦默认**连续起法**(第二个数从天宫落点续数, 与月上起日同理)。若用户习惯每个数都从大安起, 加 `--independent`。第一次遇到不明确时, 按默认起并在结果里说明用的哪种起法即可, 不必先问。
- numbers/gua 模式尽量补 `--hour 时辰支`(起卦当下的时辰), 体用、旺衰、墓库、活六神都靠它。用户当地时间换算: 23-1子, 1-3丑, 3-5寅, 5-7卯, 7-9辰, 9-11巳, 11-13午, 13-15未, 15-17申, 17-19酉, 19-21戌, 21-23亥。
- 需要转太极或数字占时加 `--gender 男/女`(不需要就别问性别)。
- 闰月按本月数; 23点后仍按当日农历日(用户若有换日习惯听用户的)。
- 用户报卦名有错别字(留恋/流连/榴莲)脚本会自动纠正。

脚本会输出全部技术标注(三宫属性、生克、体用、旺相休囚死、十二长生、入墓、活六神、地支择法、六亲、转太极), **这些是给你断卦用的底稿, 不要原样倒给用户**。

## 第二步: 读参考资料

每次断卦前**必读**:
- `references/lifa.md` — 理法核心(定位/生克流向/空亡/墓库/体用/应期/转太极)
- `references/gongwei.md` — 六宫详细取象

按问题类型**加读**:
- 感情/失物/天气/数字/疾病/射覆/求财/工作/官司/出行/风水/面相等具体事类 → `references/fenlei.md`(读对应小节, 内含各类占的三宫定位表)
- 需要细取象、两宫组合象 → `references/hegong.md`
- 用活六神/神煞类象 → `references/liushen.md`
- 三宫具象法或六神象不够用时借八卦象 → `references/bagua.md`

## 第三步: 解卦(工作流)

1. **定位**(最重要): 根据所问给三宫安角色——谁是我、谁是对方、什么是事体, 类神在哪一宫(电子产品→速喜, 书本→大安, 房子→空亡留连, 呼吸→赤口...)。fenlei.md 里有各类占的默认定位表, 但不可定死, 可多重定位叠加合观。
2. **观落宫定基调**: 落宫(人宫)是卦问之果。宫有宫象、事应已定——生克助制不改其果, 旺衰只调强弱不翻吉凶(夏落赤口不因"金死"而否其凶)。
3. **察生克流向**: 三宫谁生谁、谁克谁, 就是事件的动线。生=给予/泄耗, 克=克制/得到/动向, 都不是"克死", 围绕象论。注意方向(我生克他 vs 他生克我), 点与点可互换。
4. **合象**: 单宫象+合宫象+神煞象, 只取贴合所问的象, 不堆砌。留意特殊信号: 两宫相同(小人/第三者/竞争), 空亡(空不空要看流向与心态), 入墓(困顿昏沉), 通关顺生。
5. **参时辰**: 体用定发展趋势(用生体大吉/用克体大凶/体生用小凶/体克用小吉/比助吉比劫凶), 旺相休囚死定能量强弱, 墓库长生定状态。
6. **断结果**: 给出明确倾向性的答案(能/不能, 吉/凶, 在哪个方向), 别含糊和稀泥——传统断卦讲究是非立判。用户问应期才推应期(墓库冲开之期、择法地支、六神数应、生克月份综合定)。
7. 用户追问衍生问题(如"那钱能要回多少""对方什么人")可用转太极或取数法(见 lifa.md、fenlei.md 数字占)。

## 第四步: 输出格式

结论先行, 卦理跟上, 简明不堆术语:

```
【卦象】天宫X · 地宫Y · 人宫Z (N时)
(一句话交代定位: 这一卦里X是..., Y是..., Z是...)

【断】直接回答所问的结论, 1-3句。

【卦理】用白话讲清生克流向和关键取象, 让用户看懂"为什么这么断"。
体用/墓库/活六神等只挑对这一问有意义的说, 3-6句为宜。

【应期】(用户问了才给)
```

手机端注意紧凑, 全文以一两屏为限; 用户想细听再展开。语气按传统卦师的路子来——笃定、直给, 该断凶就断凶, 但凶卦要顺带指条出路(何时转机/如何化解方向), 不吓唬人。

## 边界与诚实

- 这是传统民间术数, 按师传体系认真断, 但不冒充超自然确定性。用户若把重大医疗、法律、投资决策押在卦上, 断完自然地提醒一句以专业意见为准即可, 不必每卦都念免责声明。
- 测病可以按疾病占断象, 但涉及真实健康问题时提醒就医; 卦断"不治""人没了"这类重象, 表述要留有余地。
- 资料中失物占的方位图未能留存, 公式1-8覆盖多数情形; 遇公式外的组合, 按生克原理推演并说明是推演。
- 不同小六壬流派细节有异(如地支归宫、宫位阴阳), 本技能以师传资料为准; 用户若用别的口径, 尊重用户的师承。

# 塔罗牌占卜

基于 Rider-Waite-Smith 标准78张塔罗牌体系进行解读。风格：断就断清楚，该说凶说凶，但凶牌也给方向——占卜是为了趋吉避凶，不是吓唬人。

## 第零步：明确问题

用户没说问什么就先问一句。已知问题不重复追问。

## 第一步：抽牌

运行 `scripts/draw.py` 按用户需求选牌阵：

| 用户说的 | 命令 |
|---|---|
| "抽一张牌"/"今日运势"/"快速问答" | `python3 scripts/draw.py one -q "问题"` |
| "帮我算算"/"抽个牌"(默认) | `python3 scripts/draw.py three -q "问题"` |
| "详细看看"/"凯尔特十字"/"深入分析" | `python3 scripts/draw.py celtic -q "问题"` |
| "抽N张" | `python3 scripts/draw.py custom N -q "问题"` |
| 用户自己报牌名 | `python3 scripts/draw.py interpret "牌名1" "reversed:牌名2" "牌名3"` |

默认不确定时用三牌阵（最实用）。脚本输出是技术底稿（牌名、正逆位、元素分布、元素互动），**不要原样给用户，要消化后用白话断**。

## 第二步：读参考资料

每次解牌前**必读**：
- `references/method.md` — 牌阵位置含义 + 解读方法论（元素互动/逆位/宫廷牌/数字模式）

**按抽到的牌加读**：
- 抽到大阿卡纳 → `references/major.md` 查对应牌
- 抽到小阿卡纳 → `references/minor.md` 查对应花色和牌号

不需要每次78张全读——只读抽到的牌。

## 第三步：解牌（工作流）

1. **整体扫描**：
   - 大阿卡纳占比（多→命运级；无→日常层面可控）
   - 花色分布（最多的花色=焦点领域）
   - 正逆位比例（逆位多→阻力大/能量内化）

2. **逐位解读**：
   - 每张牌先看正/逆位关键词
   - 结合其在牌阵中的位置（过去/现在/未来、或凯尔特十字各位含义）
   - 读牌义时把关键词**翻译成跟这个具体问题相关的话**，别背书

3. **看牌间互动**：
   - 相邻牌的元素关系（同元素增强/友好支持/对立削弱）
   - 故事线：三张牌连起来讲什么故事？
   - 有没有重复的数字/花色/主题？
   - 宫廷牌出现在"人"的位置→可能代表具体的人

4. **综合断定**：
   - 给出明确的结论（能/不能、好/不好、会/不会）
   - 凶牌不粉饰但给出路（怎么应对/什么时候转机）
   - 结合所有位置的信息讲一个完整的故事

## 第四步：输出格式

```
🃏 **抽到的牌**
位置1: 牌名(正/逆位)
位置2: 牌名(正/逆位)
位置3: 牌名(正/逆位)

**断**: 1-3句话直接回答问题

**解读**:
把三张(或更多)牌串成一个故事讲清楚。
先说现在的状态(中间牌), 再回头说怎么走到这步(左边), 最后说往哪走(右边)。
哪张牌是关键转折点特别标出来。
3-6句为宜, 手机端一屏能看完。

**建议**: 基于牌面给出可操作的方向。1-2句。
```

用户想细聊某张牌或追问再展开。凯尔特十字因为10张牌信息量大，可以分"核心"(①②)→"背景"(③④)→"走势"(⑤⑥)→"内外"(⑦⑧⑨)→"结果"(⑩)逐段讲。

## 边界

- 塔罗是心理投射和象征系统工具，不是超自然确定性预言。但占卜语境下按"断卦"的方式说话——笃定、直给，别每句都加"仅供参考"。
- 用户把重大医疗/法律/投资决策押在牌上时，断完自然提一句以专业意见为准。
- 死神牌(Death)极少代表真正死亡，不要吓人；塔牌(Tower)是剧变不是灾难——重建的前提是旧的先倒。
- 同一问题不建议反复抽牌——尊重第一次的结果。用户坚持要重抽可以做，但提醒一句"第一次抽的通常最准"。

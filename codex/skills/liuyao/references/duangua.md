# 六爻断卦核心理法

## 一、月建与日辰

月建为一卦之提纲，日辰为一卦之主宰。月日是卦爻的外部环境，决定爻的旺衰强弱。

**月建的作用:**
- 月建与爻同五行: 爻得月令旺相，力量最强
- 月建生爻: 爻得月相，次旺
- 爻生月建: 爻休，力量衰减
- 月建克爻: 爻囚，力量受压
- 爻克月建: 爻死，力量最弱
- 月建冲爻: 为**月破**，爻无力(出月方可恢复)

**日辰的作用:**
- 日辰生扶爻: 爻有日辰之助
- 日辰克制爻: 爻受日辰之克
- 日辰冲旺相之静爻: **暗动**(有动爻之力但略弱)
- 日辰冲休囚之静爻: **日破**(无力)
- 日辰合爻: 合住(牵绊)或合起(激活)
- 日辰与爻同支: **临日辰**(填实)

**月日权衡口诀:** 月为旺衰之源，日为生克之权。月定大格局(旺相休囚死)，日调具体力(生扶拱合克冲)。

## 二、用神

用神是所测之事对应的六亲爻，是断卦的靶心。

**用神宜:** 旺相、得月令、得日辰生扶、得动爻生扶、动而化进、化回头生
**用神忌:** 休囚、月破、日破、旬空、入墓、被忌神克、动而化退、化回头克、化墓化绝

## 三、原神·忌神·仇神

- **原神**: 生用神之爻(用神的靠山)
- **忌神**: 克用神之爻(用神的敌人)
- **仇神**: 生忌神之爻(忌神的帮凶)
- **喜神**: 克忌神之爻(忌神的克星)

**生克链:** 仇神 → 生忌神 → 克用神 ← 生原神 ← 克仇神

**判断逻辑:**
- 原神旺而动、忌神衰而静: 用神吉
- 忌神旺而动、原神衰而静: 用神凶
- 原神忌神俱动: 看谁力量大(月日生扶谁)
- 原神旬空或月破: 有心无力，暂不能救
- 忌神旬空或月破: 暂无威胁，但出空出月仍凶

## 四、动爻与变爻

**动爻:** 卦中最活跃的信息载体。"神兆机于动"——动必有因，动爻是事态发展的引擎。
- 动爻生用神: 吉(有人帮)
- 动爻克用神: 凶(有人阻)
- 动爻生忌神: 凶(间接害)
- 动爻克忌神: 吉(间接帮)
- 多爻皆动: 以与用神关系最密切者为主

**变爻(化爻):** 动爻变出的爻，代表动爻的发展方向和结果。
- **回头生**: 变爻生本爻 → 爻力增强(大吉)
- **回头克**: 变爻克本爻 → 爻力大损(大凶)
- **化进神**: 变爻与本爻同五行，地支向前进 → 力量增长(吉)
- **化退神**: 变爻与本爻同五行，地支向后退 → 力量萎缩(凶)
- **化墓**: 变爻为本爻之墓库 → 困顿受阻
- **化绝**: 变爻处本爻之绝地 → 力量消亡
- **化空**: 变爻逢旬空 → 力量从有至无

## 五、旬空

以日干支所在旬，旬末空出的两个地支为旬空。

**旬空含义:** 空虚、不实、落空、暂无力。

**真空与假空:**
- **假空(有救):** 旺相空、动空、日冲空(冲实)、日合空(合起) → 出空可应事
- **真空(无救):** 休囚无气又空、空而被克、安静空 → 难成事

**各爻逢空:**
- 用神空: 事情悬空不落实(假空出空可成)
- 原神空: 帮手无力
- 忌神空: 对手暂不碍事(出空仍须警惕)
- 世爻空: 自己心不定、没把握
- 应爻空: 对方不实、虚假

## 六、月破

爻受月建冲为月破，月破之爻形同虚设，不能生克他爻。

**月破规则:**
- 月破之爻发动不为破(动力可抗月冲)
- 月破之爻得日辰填实(与日支相同)不为破
- 月破之爻须出月方可恢复
- 用神月破: 事情破败，须出月才有转机
- 忌神月破: 眼前无碍

## 七、伏神

卦中六亲不全时，所缺之六亲从本宫八纯卦中查找，称为伏神。伏于该爻位下方的卦中之爻称为飞神。

**伏神有用(可出):**
- 伏神得日月生扶
- 伏神旺相
- 飞神生伏神
- 飞神旬空(门户大开，伏神可出)
- 日辰冲飞神

**伏神无用(不出):**
- 伏神休囚无气
- 飞神克伏神(压制)
- 伏神旬空且休囚

## 八、世应

- **世爻**: 代表占卦人自己
- **应爻**: 代表对方、他人、事情的对立面

**世应关系:**
- 世应相生: 彼此和合
- 世应相克: 彼此矛盾
- 世应相合: 事成、合作
- 世应相冲: 分裂、不合

## 九、六合与六冲

**六合卦:** 上下卦六爻两两相合(如天地否初四合、二五合、三六合)，主事情团聚凝合。
**六冲卦:** 上下卦六爻两两相冲，主事情散裂不成。

**变化组合:**
- 六合化六冲: 先合后散，始吉终凶
- 六冲化六合: 先散后合，始凶终吉
- 六合化六合: 和美到底
- 六冲化六冲: 散乱到底

## 十、反吟与伏吟

**反吟:** 卦爻动变后成六冲关系(地支相冲)，主反复、动荡、不安。
- 卦反吟: 主卦变卦互为六冲卦，事情反复折腾
- 爻反吟: 动爻变出与自己相冲的地支

**伏吟:** 卦爻动变后地支不变(变出与自己相同的地支)，主呻吟、忧愁、困守。
- 卦伏吟: 主变卦相同
- 爻伏吟: 动爻变出同一地支

## 十一、断卦优先级

1. **月建日辰** → 定旺衰大格局(外因)
2. **动变** → 看事态发展方向(内因变化)
3. **用神状态** → 综合月日动变后的最终结果
4. **静爻** → 辅助参考(力量最弱)

层层递进: 先看外因(月日)给用神定了什么基调，再看内因(动变)往哪个方向推，最后下结论。

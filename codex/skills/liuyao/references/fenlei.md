# 六爻分类占断法

## 一、感情婚姻

### 男测婚姻
- **用神:** 妻财爻
- 财爻旺相，得日月生扶: 对方条件好，感情顺利
- 财爻休囚空破: 感情不顺，对方条件差或无缘
- 世应相生相合: 彼此有意，可成
- 世应相克相冲: 矛盾多，难成
- 兄弟爻旺动克财: 有竞争者/情敌，或自身破财
- 官鬼爻动: 有阻碍(长辈反对、工作冲突)
- 财临玄武: 对方有暧昧、不专一
- 财临青龙: 对方端庄贤淑
- 子孙旺动: 虽财源好但克官，婚事反有障碍(女方嫌弃)

### 女测婚姻
- **用神:** 官鬼爻
- 官爻旺相: 对方有能力有担当
- 官爻休囚: 对方条件平平
- 官临白虎: 对方脾气大或有伤灾
- 官临玄武: 对方不专一、有暗昧
- 子孙爻旺动: **大忌**——克夫星，主分离、感情受挫
- 财爻动生官: 吉——有媒人或自身条件吸引对方

### 通用要点
- 世应同爻为比和: 门当户对
- 应爻空: 对方无心/不实
- 世爻空: 自己犹豫不决
- 六合卦: 婚事可成
- 六冲卦: 婚事难成

## 二、求财投资

- **用神:** 妻财爻
- 财爻旺相: 有财可得
- 财临世爻: 财来就手
- 财临应爻: 财在对方(需去求取)
- 财爻动而生世: 财来找我，大吉
- 世爻克财: 主动求财可得(但费力)
- 兄弟爻旺动: **大忌**——劫财之象，有破耗、竞争者
- 子孙爻旺动: 大吉——生财之源旺盛
- 官鬼爻动: 求财有风险、有官非牵连
- 父母爻动: 克子孙、泄财源，求财辛苦

## 三、工作事业

- **用神:** 官鬼爻(求官求职) / 世爻(看自身状态)
- 官爻旺相生世: 工作顺利，领导赏识
- 官爻克世: 工作压力大，受领导管制
- 官爻空: 目前无工作/职位虚悬
- 父母爻旺: 利考试、利文书审批
- 子孙爻旺动: 不利求官(克官)——有辞职离任之象
- 兄弟爻动: 有竞争者争抢职位
- 财爻动生官: 有人举荐(花钱打点或妻助)

## 四、疾病健康

- **用神:** 官鬼爻(官为病)
- **吉(病退):** 官鬼休囚、被子孙克制、化退化空化墓
- **凶(病重):** 官鬼旺相临世、得月日生扶、化进神
- 子孙爻旺动: 药到病除(子孙为医药之神)
- 子孙爻休囚空: 医药无效
- 世爻被官鬼克: 病在己身，较重
- 用神入墓: 昏沉不清
- 父母爻动: 泄官气但克子(药效打折)
- 重症看法: 官鬼持世旺相不受制+子孙空破，凶象重

## 五、官司诉讼

- **用神:** 世爻(己方)、应爻(对方)、官鬼(官府/案件)
- 世旺应衰: 己方有利
- 应旺世衰: 对方有利
- 世应相合: 可和解
- 世应相冲: 对抗激烈
- 官鬼生世: 官府偏向己方
- 官鬼克世: 官方不利己方
- 父母爻旺: 证据充分、文书有利

## 六、失物寻找

- **用神:** 妻财(失物) / 按具体失物六亲归类
- 财临内卦: 在家中/近处
- 财临外卦: 在外面/远处
- 财爻空: 物已不在原处
- 财爻被克: 已被他人拿走(难回)
- 财爻被合: 被藏起来(逢冲可见)
- 六神定方向: 青龙东、朱雀南、勾陈腾蛇中、白虎西、玄武北
- 卦宫方位: 乾西北、坤西南、震东、巽东南、坎北、离南、艮东北、兑西

## 七、出行

- **用神:** 世爻(出行人)
- 世爻旺相: 出行顺利
- 世爻被克入墓空: 不宜出行
- 应爻为目的地: 应旺利往，应衰不宜
- 官鬼爻动克世: 路上有灾险
- 兄弟爻动: 有破财之忧
- 父母爻旺: 舟车安全(父母为车船)

## 八、天气

- **用神:** 父母爻(雨) / 子孙爻(晴)
- 父母爻旺动: 有雨
- 子孙爻旺动: 晴天
- 父化子: 阴转晴
- 子化父: 晴转阴/雨
- 兄弟爻动: 有风
- 官鬼爻动: 有雷电

## 九、家宅风水

- 以二爻为宅(核心)，初爻为地基，三爻为门/床，四爻为户，五爻为道路，上爻为围墙
- 世爻为住户，应爻为对门/邻居
- 父母爻为房屋本体
- 二爻旺相安静: 宅运平安
- 二爻被冲克动: 宅不安宁
- 官鬼临二爻: 宅有邪气或官非
- 白虎临二爻: 宅有凶灾/病患
